# Design and asset notes

## Portrait

- Original: `assets/images/jeffrey-portrait.jpg`, supplied as `Linkedin PFP (Cropped).jpg`.
- Display variant: `assets/images/jeffrey-pixel.png`.
- Created with the built-in imagegen tool from the supplied portrait. The original is preserved and shown in the profile dialog.
- The UI label “8-BIT JEFFREY” refers to the visual style; the output file is a PNG, not an actual old-console ROM asset.

Generation prompt:

> Use case: style-transfer. Edit target: provided portrait of Jeffrey. Create a square 8-bit-style trainer portrait for a retro monster-catching RPG portfolio website. Preserve recognizable identity: same smiling face, warm brown skin, abundant curly black hair, large black rectangular glasses, navy suit, charcoal shirt and black tie. Head-and-shoulders framing like the source. Crisp, intentionally chunky square pixel clusters, limited 16-color palette, old handheld-game character portrait aesthetic. Flat pale lavender background. No antialiasing, no photorealism, no gradients, no text, no border, no extra objects. Pixel art should feel hand-drawn on a 64x64 grid, enlarged with nearest-neighbor. Keep hair fully inside the frame.

## Interface

Town buildings, paths, water, Poké Ball, and favicon are original CSS/SVG interface graphics. Press Start 2P and VT323 are loaded through Google Fonts; system monospace fonts provide an offline fallback. Optional sound effects are short synthesized square-wave tones, not sampled game audio.

Existing project, education, experience, achievement, and interest descriptions were retained. Game metaphors and dialogue are presentation; caught-project counts describe the visitor’s exploration, not additional professional qualifications.
